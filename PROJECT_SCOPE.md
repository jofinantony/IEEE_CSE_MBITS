# Project Scope: IEEE CS MBITS — "The Digital Pulse"

## Core Architecture
- **Framework**: React 19 SPA running on Vite 8 & TypeScript with Tailwind CSS v4.
- **Visual Design Identity**: Refined warm off-white canvas (`#FBFBFA`), deep near-black typography (`#121316`), IEEE heritage cobalt blue (`#00629B`), and subtle cyan accents (`#0284C7`).
- **Interaction Model**: *PULSE → CONNECT → REVEAL*.
- **3D Network Core**: Custom Three.js geodesic node lattice with Fibonacci spherical distribution, mouse parallax, cursor proximity interaction, and click pulse wave, paired with an accessible instant SVG/CSS fallback.
- **Search System**: Global `⌘K` / `Ctrl+K` command search index with instant keyboard navigation across all chapter entities.
- **Dynamic Pathway Engine**: Interactive Tech Compass linking user interest domains (AI, Systems, Cyber, Web, Cloud, IoT, Data) and action goals (Learn, Build, Compete, Research, Lead).
- **Session Trajectory Memory**: Non-intrusive Discovery Trail tracking exploration depth without third-party tracking or privacy violations.
- **Grounded AI Layer**: "Ask IEEE CS MBITS" query engine bound strictly to verified chapter records.
- **Administration**: In-session ExeCom CMS Studio with role validation and state persistence.
